# 單機版簽核工具（框架）

視窗版 Windows 程式：使用者輸入自己的帳密登入 → 列出待簽單 → 勾選 → 確認 → 送出 → 寫紀錄。

## 目前狀態
| 項目 | 狀態 |
|---|---|
| 登入視窗（帳密只存記憶體、失敗只試一次） | 完成 |
| 待簽清單、多選、確認視窗、紀錄檔 | 完成（示範模式已驗證邏輯） |
| 讀取待簽單 `list_pending()` | **待接**：需要簽核頁 HTML |
| 送出簽核 `sign()` | **待接**：需要簽核頁 HTML |
| 視窗介面（tkinter）實機測試 | **未測**：開發環境無顯示器，請在 Windows 試跑 |

## 試用（示範模式，不連網路）
```
python app.py --demo
```

## 打包成 exe（在有 Python 的 Windows 電腦）
雙擊 `build.bat`，產生 `dist\簽核工具.exe`。使用者電腦不需裝 Python。
`config.ini` 放在 exe 同一資料夾，填入 `base_url`。

## 安全設計
- 密碼不寫入檔案、不進 git，登入成功後立即從物件清除。
- 簽核一律用登入者本人身分；紀錄檔 `簽核紀錄.csv` 不含密碼。
- 不開任何本機伺服器。
