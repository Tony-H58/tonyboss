# 图片处理转HTML Skill

用户选择本机图片，自动缩图并生成HTML相册展示。

## 功能范围

| 功能 | 说明 |
|------|------|
| **批量选图** | 用户选择一个或多个图片文件 |
| **自动缩图** | 高质量缩小到指定尺寸 |
| **生成相册** | 创建响应式HTML相册 |
| **内嵌图片** | 图片 base64 编码嵌入HTML（无外部依赖） |
| **响应式布局** | PC/平板/手机都能正常显示 |
| **灯箱查看** | 点击图片可全屏查看 |
| **批量处理** | 一次处理 50+ 张图片 |

## 支持的图片格式

- JPEG / JPG（最常用）
- PNG（支持透明背景）
- WebP（现代格式，自动转 JPEG）
- GIF（转为静态 JPEG）
- BMP、TIFF（自动转换）

## 使用方式

### 基础用法
```
「生成相册」
 → 弹出文件选择对话框
 → 选择图片（支持多选）
 → 确认后自动处理
 → 保存 HTML 文件
```

### 指定缩图尺寸
```
「生成相册，缩图宽度 1920」
「生成相册，缩图 1280×800」
```

### 指定输出位置
```
「生成相册，保存到桌面」
「生成相册，保存到下载文件夹」
「生成相册，保存到项目」
```

### 高级选项
```
「生成相册，3 列布局，高质量压缩」
「生成相册，2 列布局，浅色主题」
```

## 执行流程

1. **打开文件选择** — 弹出 Windows 文件选择对话框
2. **读取图片** — 加载用户选择的所有图片
3. **图片分析** — 检测尺寸、方向、色彩空间
4. **自动旋转** — 根据 EXIF 信息纠正方向（手机照片）
5. **缩小处理**
   - 使用 LANCZOS 高质量缩放
   - 保持宽高比例
   - 长边设置为指定尺寸（默认 1280px）
6. **质量优化** — 根据压缩率自动调整 JPEG 质量（80–95）
7. **Base64 编码** — 将图片转为 base64 字符串
8. **生成 HTML** — 使用响应式模板创建相册
9. **保存文件** — 存储到指定位置
10. **验证** — 检查 HTML 完整性并在浏览器中预览

## 缩图规格（默认值）

| 设置 | 默认 | 说明 |
|------|------|------|
| **长边尺寸** | 1280px | 照片的长边缩到这个尺寸 |
| **短边最小** | 640px | 短边最少保留这个宽度 |
| **JPEG 质量** | 85 | 压缩质量（1–100） |
| **PNG 质量** | 95 | PNG 压缩质量（更高） |

## HTML 相册特性

### 布局选项
| 布局 | 列数 | 适用场景 |
|------|------|---------|
| **3 列** | 3 | 默认，PC 桌面最佳 |
| **2 列** | 2 | 平板或小屏设备 |
| **1 列** | 1 | 竖向长条图 |
| **自适应** | 自动 | 根据屏幕宽度自动调整 |

### 主题选项
| 主题 | 说明 |
|------|------|
| **浅色** | 白色背景，深色文字（默认） |
| **深色** | 深灰背景，浅色文字 |
| **高对比** | 黑色背景，白色文字 |

### 灯箱功能
- 点击图片全屏查看
- 左右箭头导航
- ESC 或点击背景退出
- 支持键盘快捷键（← → 翻页）

## 输出文件

生成的 HTML 文件包含：
- ✅ 完整的 base64 图片数据（无外部依赖）
- ✅ 响应式 CSS（自适应各种屏幕）
- ✅ 灯箱 JavaScript（开源 lightbox.js）
- ✅ 图片数量和大小统计
- ✅ 生成时间戳

**文件大小**：取决于图片数量和质量，一般 50 张照片 ≈ 20–30 MB

## 文件名约定

| 情况 | 输出文件名 |
|------|----------|
| 默认输出 | `photos_YYYYMMDD_HHMMSS.html` |
| 自定义名称 | `用户指定的名称.html` |
| 保存到项目 | `00_html file/相册_YYYYMMDD.html` |

## 注意事项

⚠️ **文件大小**
- Base64 编码会增加 ~33% 的文件大小
- 50 张高分辨率照片可能生成 30–50 MB 的 HTML
- 使用压缩工具可减小文件

⚠️ **浏览器兼容性**
- Chrome / Firefox / Safari / Edge ✅ 完全支持
- IE11 ❌ 不支持
- 移动浏览器 ✅ 良好支持

⚠️ **EXIF 方向**
- 自动读取 EXIF 信息纠正手机照片方向
- 部分古老相机可能无法正确识别

⚠️ **性能**
- 超过 100 张图片可能需要 1–2 分钟处理
- 输出的 HTML 首次加载可能较慢（浏览器解析 base64）

## 高级配置

可在 `.claude/settings.local.json` 中自定义：

```json
{
  "image-to-html": {
    "default_width": 1280,
    "default_layout": 3,
    "default_theme": "light",
    "jpeg_quality": 85,
    "png_quality": 95
  }
}
```
