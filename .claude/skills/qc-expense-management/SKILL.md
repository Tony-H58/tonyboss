# QC 出差費用與報銷管理

手動整理 QC 人員的出差費用、報銷發票、差旅費統計與支出分析。

## 一、系統概況

### 資料流向

```
支付寶/微信收據圖片
    ↓
22_import qc expense\expense rawdata
    ↓
手動辨識與整理
    ↓
QC差旅費_yymmdd.xlsx（整理記錄）
    ↓
21_qc expense chart\MK出差報銷單.html（可視化報表）
    ↓
財務部門對帳 & 核銷
```

### 目錄結構

```
E:\88. Claude\
├── 21_qc expense chart\
│   └─ MK出差報銷單.html       （HTML 報銷單）
│
└── 22_import qc expense\
    ├─ 00_plan_qc expense.xlsx  （費用預算表）
    ├─ QC差旅費_yymmdd.xlsx     （月度整理記錄）
    └─ expense rawdata\
       ├─ (未整理的圖片)
       └─ completed rawdata\    （已整理的圖片副本）
```

## 二、出差費用類別

### 可報銷費用

| 類別 | 說明 | 限制 | 憑證 |
|------|------|------|------|
| **交通費** | 高鐵、飛機、計程車 | 按實支領單 | 票根 / 電子單 |
| **住宿費** | 飯店、民宿 | 單人 ≤ 300 元/晚 | 發票 / 收據 |
| **餐費** | 工作餐、接待餐 | 按實支領單 | 電子發票 / 小票 |
| **門票費** | 訪廠、參展 | 按實支領單 | 票根 |
| **雜支** | 停車、行李、Wi-Fi | 按實支領單 | 收據 |

### 不可報銷費用

| 項目 | 原因 |
|------|------|
| 個人消費品 | 衣服、禮品、日化品 |
| 罰款 | 超速罰款、違停罰單 |
| 娛樂消費 | KTV、電影票 |
| 親屬同行費用 | 家人出差費 |
| 預估費用 | 無實際支出憑證 |

## 三、月度報銷流程

### 第 1 週：收集與拍照

```
1. QC 人員出差回公司
   ↓
2. 整理所有紙質收據
   ↓
3. 拍照上傳到微信群組
   - 角度清晰（能看清金額）
   - 光線充足（避免反光）
   - 每張獨立拍照（不疊在一起）
   ↓
4. 圖片存儲位置
   22_import qc expense\expense rawdata\
   ├─ 微信圖片_20260601135246_738_1.jpg
   ├─ 微信圖片_20260601163827_739_1.jpg
   └─ ...
```

### 第 2 週：人工辨識與整理

```
1. 開啟 QC差旅費_yymmdd.xlsx
   ↓
2. 逐張檢查收據圖片
   → 打開 expense rawdata 資料夾
   → 邊看圖片邊在 Excel 中輸入
   ↓
3. 填寫以下欄位
   - 日期（發票日期）
   - QC 人員（出差者名字）
   - 類別（交通 / 住宿 / 餐費等）
   - 項目說明（如「上海飛台北機票」）
   - 金額（人民幣或台幣）
   - 是否可報銷（是 / 否）
   - 備註（任何需要說明的地方）
   ↓
4. 記錄完成後
   → 將該圖片複製到 completed rawdata
   → 防止重複記錄
   ↓
5. 完成整月記錄
```

### 第 3 週：費用統計與審批

```
1. 計算月度費用合計
   ↓
2. 透過 Pivot Table 或 SUMIF 統計
   - 按 QC 人員統計
   - 按費用類別統計
   - 按是否可報銷分類
   ↓
3. 檢查異常
   → 是否有超額費用？
   → 是否有不可報銷項目混入？
   → 金額是否與原始收據相符？
   ↓
4. 送審
   → 經理審批
   → 財務部門核銷
   ↓
5. 歸檔
   → 將 completed rawdata 中的圖片備份
   → 保存 Excel 檔案
```

### 欄位定義

| 欄位 | 類型 | 輸入規則 | 範例 |
|------|------|---------|------|
| **日期** | 日期 | YYYY/MM/DD | 2026/06/01 |
| **QC人員** | 文字 | 員工全名 | 王小明 |
| **類別** | 下拉單 | 交通/住宿/餐費/門票/雜支 | 交通費 |
| **項目說明** | 文字 | 簡短描述 | 上海飛台北機票 |
| **金額** | 數字 | 正數，最多 2 小數位 | 1200.00 |
| **幣別** | 下拉單 | CNY / TWD | CNY |
| **可報銷** | 下拉單 | 是 / 否 | 是 |
| **備註** | 文字 | 額外說明 | 7 人晚餐 |

### 自動計算公式

```excel
# 月度合計（在總結工作表）
=SUMIF(費用表!$G:$G,"是",費用表!$E:$E)

# 按人員分類統計
=SUMIFS(費用表!$E:$E,費用表!$B:$B,"王小明",費用表!$G:$G,"是")

# 按類別統計
=SUMIFS(費用表!$E:$E,費用表!$C:$C,"交通費",費用表!$G:$G,"是")
```

## 六、常見整理錯誤與排查

| 錯誤 | 症狀 | 原因 | 解決方案 |
|------|------|------|---------|
| 重複記錄 | 同一張收據記了兩遍 | 沒有移至 completed | 檢查 Excel 中的日期/金額是否重複，刪除多餘行 |
| 金額錯誤 | Excel 中的金額與圖片不符 | 手動輸入時打錯字 | 逐張檢查圖片，更正金額 |
| 幣別混亂 | CNY 和 TWD 混用 | 沒有統一轉換 | 在計算總額時按幣別分類，或統一轉為 TWD |
| 日期格式不一 | 有些是 2026/6/1，有些是 2026/06/01 | Excel 未統一格式 | 全選日期欄 → 格式 → 設為 YYYY/MM/DD |
| 人員名字不統一 | 同一人有「王小明」和「王明」兩種寫法 | 手動輸入不一致 | 使用資料驗證下拉單限制輸入選項 |
| 類別選項錯誤 | 填入「車費」而非「交通費」 | 沒有按照規範 | 使用下拉單，只允許 5 種類別 |

## 九、常見問題

### Q: 多人同時出差怎麼記錄？

**A:** 在「日期」、「QC人員」、「類別」欄分別填寫每個人的費用。系統會自動按人員統計。

```excel
| 日期 | QC人員 | 類別 | 項目說明 | 金額 |
|------|--------|------|---------|------|
| 2026/06/01 | 王小明 | 交通費 | 機票 | 1200 |
| 2026/06/01 | 李芳芳 | 交通費 | 機票 | 1200 |  ← 同日不同人
| 2026/06/02 | 王小明 | 住宿費 | 飯店 | 280 |
```

### Q: 某筆費用無法分類怎麼辦？

**A:** 使用「雜支」類別，並在備註欄詳細說明。審批者會判斷是否可報銷。

```excel
| 類別 | 項目說明 | 金額 | 備註 |
|------|---------|------|------|
| 雜支 | 緊急維修行李箱 | 200 | 出差中行李箱拉鍊壞掉 |
```

### Q: 港幣、日幣等其他幣別怎麼辦？

**A:** 在「幣別」欄填「其他」，在備註欄註明幣種和匯率。由財務部門統一轉換。

```excel
| 幣別 | 金額 | 備註 |
|------|------|------|
| 其他 | 5000 | 日幣 JPY，匯率 1:0.23 |
```

### Q: 損壞的收據圖片無法辨識怎麼辦？

**A:** 在備註欄標註「圖片不清，待補」，或要求員工重新拍照。若無法補交，無法報銷。

```excel
| 項目說明 | 金額 | 備註 |
|---------|------|------|
| 不詳 | 1500 | 圖片不清，已通知員工補正 |
```
