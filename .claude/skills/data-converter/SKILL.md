# 数据格式转换 Skill

实现 CSV、Excel、HTML 之间的双向格式转换，保留数据完整性和格式。

## 功能范围

| 转换方向 | 说明 |
|---------|------|
| **CSV → Excel** | 自动检测分隔符、编码，支持合并单元格 |
| **Excel → CSV** | 导出单个工作表或全部工作表 |
| **Excel → HTML** | 生成排序/筛选功能的交互式表格 |
| **HTML → Excel** | 从网页表格提取数据到 Excel |
| **CSV → HTML** | 生成可视化 HTML 表格 |
| **HTML → CSV** | 提取表格数据为 CSV |
| **批量转换** | 一次处理多个文件 |
| **格式保留** | 保留数字格式、日期、货币、颜色 |

## 支持的数据格式

### 输入格式
- **CSV**：`,` / `;` / `\t` / `|` 自动检测分隔符
- **Excel**：`.xlsx` / `.xls`（支持多工作表）
- **HTML**：`<table>` 标签（支持多个表格）
- **TSV**：Tab 分隔符文本

### 输出格式
- **XLSX**（Excel 2007+）
- **CSV**（UTF-8 编码）
- **HTML**（自适应表格）
- **JSON**（可选）

## 执行流程

### CSV → Excel 流程
1. **打开文件** — 读取 CSV 文件
2. **检测编码** — 自动识别 UTF-8/BIG5/GBK
3. **检测分隔符** — 分析第一行确定分隔符
4. **解析数据** — 逐行读取，智能检测数据类型
5. **类型转换**
   - 日期格式识别（YYYY-MM-DD、YYYYMMDD 等）
   - 数字格式识别（整数、小数、百分比、货币）
   - 布尔值识别（True/False、是/否）
6. **写入 Excel** — 应用对应的单元格格式
7. **自动列宽** — 根据内容调整列宽
8. **生成索引** — 添加行号列（可选）
9. **保存** — 输出 .xlsx 文件

### Excel → HTML 流程
1. **打开工作簿** — 读取所有工作表
2. **选择工作表** — 用户选择要导出的工作表
3. **提取数据** — 逐行逐列读取
4. **保留格式**
   - 单元格背景色 → CSS 背景色
   - 文字加粗/斜体 → HTML 标签
   - 数字格式 → 自动对齐（靠右对数字）
   - 行高/列宽 → CSS 样式
5. **添加交互功能**
   - 排序（点击表头排序）
   - 筛选（下拉菜单筛选）
   - 搜索（顶部搜索框）
6. **生成 HTML**
   - 内嵌 CSS（响应式设计）
   - 内嵌 JavaScript（排序、筛选）
   - 兼容移动设备
7. **保存** — 输出独立 HTML 文件

### HTML → Excel / CSV 流程
1. **解析 HTML** — 识别所有 `<table>` 标签
2. **提取表格** — 逐行逐列读取单元格
3. **合并单元格识别** — 检测 `colspan` / `rowspan`
4. **去除格式** — 移除 HTML 标签，保留纯数据
5. **类型检测** — 识别数字、日期、文本
6. **去重（可选）** — 移除重复行
7. **导出** — 保存为 Excel 或 CSV

## 数据类型检测

系统自动识别并保留数据类型：

| 原始值 | 检测类型 | Excel 格式 | 说明 |
|--------|---------|----------|------|
| `2026-06-04` | 日期 | Date (YYYY-MM-DD) | ISO 格式日期 |
| `260604` | 日期 | Date (YY/MM/DD) | 项目常用日期 |
| `12345` | 数字 | Number | 整数 |
| `123.45` | 数字 | Number (2 位小数) | 小数 |
| `123,456.78` | 数字 | Number (格式化) | 千位分隔符 |
| `$1,234.56` | 货币 | Currency (USD) | 货币格式 |
| `¥1,234.56` | 货币 | Currency (CNY) | 人民币 |
| `45%` | 百分比 | Percentage | 百分比 |
| `TRUE` / `FALSE` | 布尔 | Boolean | 是/否 |
| `其他` | 文本 | Text | 纯文本 |

## 输出文件

### Excel 输出
- 工作表名称：保留原名或自动生成
- 冻结表头：第一行自动冻结
- 自动筛选：表头行启用自动筛选
- 格式：`.xlsx` 格式

### HTML 输出
- 响应式表格：PC/平板/手机都能显示
- 排序功能：点击表头排序（升序/降序）
- 筛选功能：表头下拉菜单快速筛选
- 搜索功能：全表快速搜索
- 分页功能：大表格自动分页（可选）
- 导出按钮：可重新导出为 CSV
- 深色模式：自动适配系统深色模式

### CSV 输出
- 编码：UTF-8（默认）或 Big5/GBK
- 分隔符：`,` / `;` / `\t`（用户选择）
- 引号：自动处理含特殊字符的单元格
- 换行：保留原换行符

## 注意事项

⚠️ **编码问题**
- 自动检测编码（UTF-8、BIG5、GBK）
- 若检测失败可手动指定

⚠️ **数据丢失**
- CSV → Excel：保留所有数据和格式
- Excel → CSV：丢失公式（保留计算结果）
- 合并单元格：转换为独立单元格

⚠️ **公式处理**
- **CSV → Excel**：纯数据导入，无法识别公式
- **Excel → CSV**：公式转换为计算结果
- **Excel → HTML**：公式转为值

⚠️ **大文件处理**
- 超过 1 万行的文件，可能需要 10–30 秒处理
- 超过 10 万行的文件，建议分割后转换

⚠️ **特殊字符**
- 自动处理含有逗号、引号、换行的数据
- 若转换后出现乱码，检查源文件编码

## 高级配置

`.claude/settings.local.json` 中可自定义：

```json
{
  "data-converter": {
    "default_encoding": "utf-8",
    "default_delimiter": ",",
    "freeze_header": true,
    "auto_filter": true,
    "html_theme": "light",
    "html_add_search": true,
    "html_add_pagination": false
  }
}
```
