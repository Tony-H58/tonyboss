# 下载任务管理 Skill

统一管理项目中的各类下载任务，包括周报 rawdata、月报 rawdata、验布报表等。

## 功能范围

| 功能 | 说明 |
|------|------|
| **单文件下载** | 下载指定的报表或 rawdata |
| **批量下载** | 同时下载多个文件，并发处理 |
| **自动分类** | 按类型自动整理到对应文件夹 |
| **断点续传** | 网络中断时支持续传 |
| **进度跟踪** | 实时显示下载进度 |
| **完成验证** | 下载完成后验证文件完整性 |

## 支持的下载类型

| 类型 | 来源 | 目标文件夹 | 触发词 |
|------|------|----------|--------|
| 周报 rawdata | QC Portal / Factory Portal | `03_download rawdata/weekly_raw/` | 「下载周报」、「周报 rawdata」 |
| 月报 rawdata | QC Portal / Factory Portal | `03_download rawdata/monthly_raw/` | 「下载月报」、「月报 rawdata」 |
| 验布报表 | 内部系统 | `03_download rawdata/reports/` | 「下载验布报表」 |
| 发票 rawdata | 平台发票 Excel | `31_electronic invoice/invoice rawdata/` | 「下载发票」 |

## 使用方式

### 单文件下载
```
下载周报 yymmdd-yymmdd
下载月报 yymmdd-yymmdd
```

### 批量下载
```
批量下载周报 260601-260630
批量下载月报 260501-260630
```

### 自动下载（使用默认日期范围）
```
自动下载周报      ← 下载上周四到本周三的周报
自动下载月报      ← 下载上月的月报
```

## 执行流程

1. **验证输入** — 检查日期格式和网络连接
2. **建立连接** — NTLM 认证到服务器
3. **获取文件列表** — 查询可下载的文件
4. **并发下载** — 最多 4 个并发任务
5. **进度报告** — 实时显示下载进度
6. **完整性检查** — 验证文件大小和内容
7. **自动分类** — 按类型移动到对应文件夹
8. **日志记录** — 记录下载成功/失败状态

## 配置

| 设置 | 默认值 | 说明 |
|------|--------|------|
| 最大并发数 | 4 | 同时下载的文件数 |
| 超时时间 | 300s | 单文件下载超时 |
| 重试次数 | 3 | 失败重试次数 |
| 输出目录 | `E:\88. Claude\03_download rawdata\` | 根下载目录 |

## 注意事项

⚠️ **日期格式**
- 使用 YYMMDD（如 `260604`）或 YYYYMMDD（如 `20260604`）
- 日期范围用 `-` 分隔（如 `260601-260630`）

⚠️ **文件覆盖**
- 同名文件会自动备份（添加 `.bak` 后缀）后覆盖
- 在 rawdata 文件夹中，已有 `Imported_` 前缀的文件会被跳过

⚠️ **网络问题**
- 若下载中断，重新执行相同命令会断点续传
- 不会重复下载已完成的文件

**场景 3：下载指定发票**
```

 → 下载 2026 年 2 月平台发票
 → 存入 invoice rawdata/

```
