# 平台發票辨識轉入

把 `平台發票-114-X.xlsx` 裡**內嵌在工作表中的發票圖片**（不是儲存格資料）辨識出來，
算好未稅金額，寫進 `發票整理記錄_yymmdd.xlsx` 的「發票明細」工作表。

## 輸出檔命名

資料以**累加**方式寫入同一檔案，依月份順序逐月追加。

- **進行中**（全年未完成）：`發票整理記錄_yymmdd.xlsx`，`yymmdd` = 當天處理日期
  - 例：`發票整理記錄_260604.xlsx`
- **全年完成後**：改名為 `發票整理記錄_yyyy.xlsx`，`yyyy` = 發票所屬西元年
  - 例：`發票整理記錄_2025.xlsx`

## 欄位結構（發票明細）

| 欄 | 欄位 | 來源 |
|----|------|------|
| A | 賣方名稱 | 圖片 |
| B | 賣方統編 | 圖片 |
| C | 買方名稱 | 由 D 欄統編比對 NameList |
| D | 買方統編 | 圖片 |
| E | 發票號碼 | 圖片 |
| F | 發票日期 | 圖片 |
| G | 交易日期（費用期間） | 圖片 |
| H | 總計 | 計算 = I + J |
| I | 應稅銷售額 | 圖片 |
| J | 稅額 | 圖片 |
| K | Uber費用 未稅金額 | 計算 = I − 其他所有品項 |
| L | 廣告費用 未稅金額 | 計算 |
| M | 附加服務費 未稅金額 | 計算 |
| N~T | 品項 4~10 未稅金額 | 計算 |

## 計算規則

```
品項未稅 = round(含稅 / 1.05)
K（Uber費用未稅） = I − 其他所有品項未稅     ← 用差額回推，確保 K+L+M = I
H = I + J
```

**K 一定要用差額回推**，不要各自 round 後相加，否則會因為進位造成 K+L+M ≠ I。

## 執行流程

xlsx 本質是 zip，發票圖片存在 `xl/media/`。

1. **解壓提取圖片** — 把 xlsx 當 zip 解開，取出 `xl/media/` 下的發票影像到暫存資料夾
2. **批量讀圖辨識** — 一次讀 12 張以上，直接整理數據，不要逐張列出說明
3. **計算未稅金額** — 依上面的計算規則，Uber 費用用差額回推
4. **寫入發票整理記錄** — 一次性寫入，不要逐列寫
5. **二次讀圖比對驗證** — 重新讀圖核對已寫入的資料
6. **有差異則修正** — 修正後再比對，直到完全正確
7. **套用格式** — 見下方格式設定
8. **清理暫存圖片**
9. **歸檔** — 整個 xlsx 的**所有工作表**都處理完成後，才把來源檔移到 `completed rawdata\`
10. **更新筆記** — 更新 `發票整理筆記.md` 的完成進度表

## 格式設定

Excel 對齊常數：

```
xlLeft   = -4131
xlRight  = -4152
xlCenter = -4108
```

- **標題列**：置中 + 粗體
- **A~G 欄**：靠左（含 F 發票日期、G 交易日期）
- **H~T 欄**：靠右（數字金額欄）

## 執行準則

使用者說「**執行**」= 轉入發票資料，一次性完成所有工作表。

- ✓ 不須列出圖片及說明，直接整理數據
- ✓ 執行中所有權限都已授予，直接操作，無需詢問
- ✓ 不須再詢問使用者確認，直接執行完成
- ✓ 跨年規則：若發票跨年，先 copy 舊檔保留 → 清空原檔資料 → 輸入新年度資料

減少中間詢問可提升速度 3–5 倍。
