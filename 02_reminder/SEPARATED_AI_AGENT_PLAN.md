## 🤖 系統 2: 郵件智能分析系統（AI 試驗 1）

**目標**: 自動化處理預警/異損/一般郵件

### 核心功能

#### 2.1 自動分類
```
郵件進來 → AI 閱讀 → 自動分類
├─ 緊急告警（需立即處理）
├─ 異損通知（需記錄和分析）
├─ 一般資訊（存檔）
└─ 垃圾（刪除）

準確率目標: > 90%
```

#### 2.2 自動提取重點
```
原文: 「產品 XYZ 在 8 月 15 日檢驗時發現...」
AI: 提取
├─ 產品: XYZ
├─ 日期: 2026-08-15
├─ 問題: [異損原因]
└─ 建議: [解決方案]
```

#### 2.3 自動生成摘要
```
每日彙總郵件:
「今日收到 5 封郵件
├─ 緊急告警: 1 封（已記錄）
├─ 異損通知: 2 封（平均缺陷率 2.3%）
├─ 一般資訊: 2 封
└─ 建議: 檢查生產線 XYZ」
```

#### 2.4 自動回覆（可選）
```
某些郵件自動回覆:
「感謝通知，已收悉並記錄。將在 24 小時內處理。」
```

### 技術實現

**架構**:
```
Outlook 郵件
    ↓
Python/PowerShell 讀取
    ↓
Claude API 分析
    ↓
自動分類 + 提取 + 生成摘要
    ↓
寫入數據庫/日誌
    ↓
發送摘要郵件給用戶
```

**觸發方式**:
- 每小時檢查一次新郵件
- 或手動觸發

**成本估算**:
- 每天 20 封郵件 × 300 tokens/郵件 = 6000 tokens/天
- 每月 180,000 tokens ≈ $0.15
- **實際: $10/月**（包含緩衝）
